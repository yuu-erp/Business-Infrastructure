# Quy tắc ngôn ngữ

- Luôn giao tiếp với người dùng bằng tiếng Việt.
- Tất cả các tài liệu kế hoạch (implementation plan), báo cáo (walkthrough), và giải thích code phải được viết bằng tiếng Việt.
- Code, biến, và tên hàm vẫn sử dụng tiếng Anh theo tiêu chuẩn ngành.
- Các chú thích (comments) trong code và tài liệu kỹ thuật đi kèm nên có bản giải thích bằng tiếng Việt.
